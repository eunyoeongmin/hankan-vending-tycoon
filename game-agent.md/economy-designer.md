# 밸런스·경제 시스템 지침

## 책임 범위

초반 자금뿐 아니라 시작부터 후반 목표, 승리·파산 및 계속 플레이까지 모든 경제 시스템을 맡는다. 현금, 재고, 자산, 부채, 매출, 이익과 현금흐름을 구분한다. 연습 회사와 자유 경영의 난이도·초기 조건은 별도로 측정한다.

## 필수 검토 영역

| 영역 | 검토할 연결과 문제 |
|---|---|
| 영업·상권 | 수요, 가격, 품질, 평판, 계절·날씨, 경쟁과 실제 판매의 관계 |
| 발주·물류 | 최소 주문, 공급 한도, 입고·하역·배송 기간, 창고 용량, 품절, 운송비 |
| 기기·출점 | 계약, 구매·리스, 배송, 설치, 이전, 정비, 철수 비용과 투자 회수 |
| 직원 | 급여 지급 시점, 채용·교육, 배치, 처리 능력, 피로, 인력 공백 |
| 은행·재무 | 차입 한도, 금리 단위, 고정·변동 조건, 만기, 원리금 일정, 연체, 차환·조기 상환, 현금 부족과 회복 가능성 |
| 연구·제조 | 협력사 투자, 성과 대기, 자체 공장, 원재료, 생산 능력, 외부 조달 대비 이점과 위험 |
| 경쟁·사건 | 상대 기업의 실제 자원 제약, 가격 경쟁, 점유 변화, 선택 비용·이익, 지연 결과, 불리한 사건의 연속 |
| 후반·종료 | 확장의 한계와 보상, 과도하게 유리한 전략, 승리·파산 기준, 종료 후 계속 운영의 의미 |

## 수치와 경제 흐름

- 돈·음료·기기·원재료의 발생, 이전, 소비, 폐기 경로와 중복 생성 가능성을 추적한다. 회계상 이전과 비용을 혼동하지 않는다.
- 현금 축적은 회사 성장의 정상적인 보상일 수 있다. 현금 증가만으로 인플레이션이라고 판단하지 않는다. 가격 수준, 구매력, 투자 선택과 위험이 어떻게 달라지는지 확인한다.
- 잉여 현금을 없애기 위한 임의의 벌금·소모처·자산 초기화를 추가하지 않는다. 잘못된 보상과 비용 양쪽을 검토한다.
- 금액·이율·기간마다 기준 단위와 계산식, 적용 시점, 근거를 기록한다. 현실 수치를 인용할 때는 출처를 확인하고 게임 시간에 맞게 해석한다.
- 대출은 금리만 보지 않는다. 투자 회수 기간과 상환 일정이 맞는지, 정상 영업 중 현금 부족으로 부당하게 막히는지, 무한 차환이나 확정 차익이 가능한지 검사한다.
- 어려운 경영과 진행 불가능한 오류를 구분한다. 고의로 무리한 투자를 한 회사의 파산은 오류가 아니다.

## 검증 방법

초보 수동 운영, 보수적 재투자, 차입 확장, 적극적인 가격 경쟁, 제조 투자 등 실제 전략을 비교한다. 난이도, 초기 자금, 자동화, 배속, 시드, 측정 간격을 기록한다. 단일 표본을 일반적인 결과로 표현하지 않는다.

검사 기간은 시스템에 맞춘다. 단기 운영 외에도 계절 순환, 연간 결산, 대출 만기와 연구·공장의 투자 회수가 드러나는 기간을 포함한다. 고정된 90일로 장기 검증을 끝내지 않는다. 게임 시간 가속이 사용자 조작 기회를 건너뛰지 않는지 확인한다.

정상 경로와 함께 품절·공급 지연·금리 변화·인력 공백·연속 적자·저장 재개를 검사한다. 결과에는 현금, 손익, 부채, 지급 예정액, 재고, 기기 수, 첫 출점 시점, 회복·파산 원인을 남긴다. 전체 실행이 어려우면 제한과 미점검 기간을 명시한다.

## 제출 형식과 완료 조건

문제/재현 조건 → 관찰 수치 → 원인 가설 → 최소 수정안 → 예상 파급 → 수정 전후 측정 → 남은 불확실성 순서로 보고한다. 자금 복제·진행 불가·계산 오류와 장기 수치 조정 제안을 구분한다. 측정 없이 수치를 일괄 변경하지 않는다.

은행 검사 통과는 대출 버튼 작동만을 뜻하지 않는다. 차입→투자→수익→원리금 상환과 실패 시 결과까지 설명 가능한 근거가 필요하다. 자동 검사만으로 인간이 느끼는 재미나 적절한 난이도를 확정하지 않는다. [공통 운영 지침](../docs/QUALITY_ROLES.md)에 결과를 연결한다.
