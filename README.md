# 한 칸 상회 · 기업 경영판

한국어/일본어, USD 통화의 독립 실행 HTML 경영 게임입니다. 외부 API나 서버 없이 실행되며 자동 저장은 현재 브라우저에 남습니다.

## 빌드와 검증

- `python build.py`: `src/base.html`, `src/enterprise.js`, `src/rivalry.js`, `src/scenario.js`, `src/enterprise.css`를 합쳐 `dist/index.html`과 작업 폴더의 `vending-tycoon.html`을 생성합니다.
- Node 24에서 `npm install` 후 `npm test`로 고객·재고·회계·시간·버튼 회귀 검사를 실행합니다.
- 배포 대상은 `dist`입니다. HTML 파일을 직접 열어서도 플레이할 수 있습니다.

## 경영 시스템

- 기기별 4슬롯: 상품·가격·자체 브랜드 설정. 품목 변경 시 남은 재고를 창고로 반환합니다.
- 고객은 가격 민감도, 상품 선호, 날씨·계절, 기기 상태, 품질·브랜드와 경쟁사를 고려합니다. 구매 기록이 재고·매출·화면 속 구매 장면의 공통 기준입니다.
- 지역 도매(1일/최소40), 공장 직거래(2일/최소100), 특급 공급(0.25일/최소20). 원가 지수와 공급처가 매입가에 반영됩니다.
- 발주 대금은 즉시 현금에서 지불합니다. 운송 중 재고와 창고 재고는 자산이며, 기기에 보충해도 추가 비용으로 처리하지 않습니다. 판매 시 실제 평균 매입 원가를 비용으로 인식합니다.
- 긴급 매입은 기본 원가 지수의 125%이며 공급 부족을 메웁니다. 자동 발주와 직원 보충을 함께 쓰면 운영 자동화가 가능합니다.
- 품질·물류 투자, 상권별 광고, 자체 브랜드, 기기 마모·정비를 제공합니다.
- 경쟁사는 상권별 가격과 예상 수익성에 따라 운영 수익을 얻고 출점 입지를 평가합니다. 경쟁사 고객은 개별 애니메이션 대신 일별 추정으로 계산합니다.
- 기기별 구매 실패 원인, 상품별 매출총이익, 최대60일 결산 보관 및 최근 자금 이동을 제공합니다.

## 저장과 호환성

기존 v5 저장에 `enterprise`와 기기별 `slots`를 추가합니다. 기존 날짜·현금·재고·진행 중 영업은 유지합니다. 최초 이전 전 저장을 별도 로컬 저장 키에 백업합니다. 추가 상태도 로드 검증에 포함합니다.

1배속 하루3분과 0.5/2/4배속은 유지합니다. 메뉴·다른 탭에서는 시간이 멈춥니다. 버튼은 실시간 화면 갱신 중 재생성하지 않습니다.

## 모델의 범위

자판기 유통 회사에 집중한 경제 모델입니다. 제조 공장, 주식시장, 다업종 그룹 경영은 포함하지 않습니다. 기존 이벤트의 비용·보상과 연구·민원 처리도 결산에 반영합니다. 기업 경영판의 결산은 실제 상품 원가 및 광고·정비·본사 비용을 포함하며, 보상 수입은 기타 순비용에서 차감합니다.
## 언어 진입과 경쟁 전략 확장

- 첫 접속은 브라우저의 선호 언어 목록에서 한국어/일본어를 찾습니다. 저장된 언어 선택이 우선하며 `?lang=ja` / `?lang=ko` 링크로 바로 시작할 수도 있습니다.
- 시작·설정·도움말 등 대화창 맨 위에 항상 `한국어 / 日本語` 전환 버튼을 표시합니다.
- 경쟁 전략 화면에 양쪽 회사의 예상 선택률과 경쟁 행동·전황을 표시합니다. 상대 실제 현금·손익·자금 부족 횟수는 내부 계산에만 사용합니다. 같은 가격·품질·재고·브랜드 지표가 실제 구매 압력과 경쟁사의 추정 영업이익에 반영됩니다.
- 플레이어는 상권별 맞불 할인(3일, 실제 결제 가격 15% 할인), 단골 확보(5일), 방어 광고(3일) 중 하나를 운영합니다. 비용은 현금과 손익에 반영하며 중복 적용을 막습니다.
- 경쟁사는 하루 전 공세를 예고하고, 기간과 자금 제약 안에서 가격·광고 전략을 사용합니다. 현금이 부족하면 공세를 취소하고 기기를 처분합니다. 자금 부족이 5일 연속 지속되면 철수합니다. 철수는 성과로 기록되며 게임은 계속됩니다.
- 상대는 자금난에 빠진 플레이어에게 인수 제안을 보낼 수 있습니다. 플레이어 기기의 매각은 직접 수락해야 실행됩니다. 플레이어의 파산·은행 엔딩 규칙은 유지합니다.

## 시작 조건과 개발 메모

새 게임에서 입문·표준·도전·극한 프리셋과 9개 세부 조건을 선택합니다. 선택은 게임별로 저장되며 현재 게임 설정에서 조회할 수 있습니다. 기존 저장의 규칙은 유지합니다. 설정 난도 지수는 표준100인 자체 참고값입니다.
