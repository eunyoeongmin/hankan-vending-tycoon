# 10.8 수치 조정 · 레퍼런스와 전략 비교

Economy Designer / 2026-09-15. 목적은 같은 조건에서 가격·투자·차입 선택의 차이를 확인하고, 앞선 10.7 점검에서 남은 과도하게 빠른 자력 출점을 조정하는 것이다. 전체 게임의 최종 난이도나 인간이 느끼는 재미를 확정한 결과는 아니다.

## 레퍼런스에서 가져온 원칙

- Capitalism Lab의 공식 제품 정의는 기준가격, 소비자의 연간 수요, 가격·품질·브랜드 관심도, 운송비를 별도 변수로 취급한다. 우리 게임도 자금 총액을 임의로 없애기보다 **실제 구매 기회와 상품 가격 정책**을 조정한다. 원작의 판매가격이나 수요 절대값은 가져오지 않았다. [공식 제품 모딩 문서](https://www.capitalismlab.com/mod/advanced-modding/advanced-modding-products/)
- 공식 입문 안내는 상품별로 가격·품질·브랜드의 상대 중요도가 다르며, 연구와 공급 품질을 상품 전략에 연결하도록 설명한다. 여기서는 비용 배수만으로 자동가격을 정해 두 정책이 같은 최저가가 되던 문제를 고친다. [공식 입문 안내](https://www.capitalismlab.com/beginners-guide-gameplay-basics/)
- OpenTTD의 공식 경제 설명은 차입 이자를 월별 지급하며, 대출과 유지비·경제 조건을 구분한다. 이 게임에서도 **신규 투자액, 매월 지급액, 실제 운영비**를 분리해 비교하고 공장 유지비 누락을 수정한다. OpenTTD의 대출액·금리는 복사하지 않는다. [공식 경제 문서](https://wiki.openttd.org/en/Manual/Economy)

## 변경 숫자와 근거

| 변경 | 이전 → 이후 | 근거와 적용 범위 |
|---|---|---|
| 현대 모드 일 구매 수요 규모 | 기존 계산 ×1 → ×0.6 | 단일 기기 표준 운영만으로 28일에 자력 출점하던 표본을 47~51일로 이동. **우리 게임의 1~2개월 첫 자력 출점 설계 가설**에 따른 값이며 원작 수치가 아님. 모든 회사가 같은 상권 고객을 나눠 갖는 규칙 유지 |
| 자동 마진 가격 | 원가×2.2 → max(원가×2.2, 상품 기준가격×SKU 용량/350) | 시작 상품의 저원가에서 점유율 정책과 같이 $0.80에 붙던 문제 해결 |
| 자동 점유율 가격 | 원가×1.7 → max(원가×1.7, 용량 보정 기준가격×0.85) | 기준 대비 15% 할인과 원가 배수 하한을 함께 사용. 가격 자체가 낮다고 항상 최종 이익이 높아지지는 않음 |
| 실제 공장 고정비 | $0/일 → $2/일 | 제조 분석에는 이미 $2/일이 있었지만 실제 현금 지출은 없었음. 완공 후 가동·유휴 모두 비용 발생. 사업장 보고서 중복 가산도 제거 |

수요는 다음 영업일 고객 생성부터 반영한다. 기존 기기 장부가·이미 체결한 대출·연구 계약·수동 지정 가격을 바꾸지 않는다. **저장된 자동 마진/점유율 정책은 다음 자동 운영부터 새 계산을 사용한다.** 정책이 켜진 회사에 대한 이 행동 변경은 의도된 패치이며, 모든 저장의 경제 행동을 동결한 것은 아니다.

신규 기기 견적 배수를 12→18로 올리는 별도 후보도 시험했지만 채택하지 않았다. NPC 증설을 늦춰 단일 기기 플레이어의 잉여가 오히려 늘어나는 표본이 있었기 때문이다. 기기 가격·공장 건설비·급여·금리·기존 계약은 이번에 일괄 조정하지 않았다.

## 함께 수정한 진행 오류

3대 출점으로 직원이 생긴 표본에서 경쟁사가 직원을 스카우트하면 `refOperationsAdvance`가 `other.ops.jobs.filter`를 호출해 예외가 났다. 플레이어의 작업 큐는 `state.jobs`이므로 플레이어/경쟁사의 실제 큐를 구분해 정리하도록 수정한다. 경제 비교의 수정 전·후 모두 이 공통 크래시 수정만 먼저 적용했다. 크래시를 계속 실행한 척하지 않았다.

수정 파일: `src/management-operations.js`, `src/reference-hooks.js`, `src/reference-operations.js`, `src/reference-finance.js`.

**제조의 투자 회수가 적정해졌다는 근거는 아직 없다.** 초기에 연구에 자금을 배정하면서 출점과 입지 확보가 늦어지고, 적은 기기로는 공장을 충분히 활용하지 못한다. seed 7 제조 회사는 같은 상권에서 1대를 유지한 반면 재투자는 3대가 되어, 현금 차이를 공장 하나의 순수 ROI로 읽을 수 없다. 품질·자체 브랜드·외부 도매 확장을 포함한 산업 전략 비교가 더 필요하다.

현대 표준 시작 상태의 같은 350ml 기준 단가는 Aqua 외부 매입 $0.475, Sun $0.54, 자체 음료의 품질1 원재료 합 $0.368이다. 공장 신규 건설비 $7,200, 기술1 연구 예산 $600이 선행한다. 배치 분석의 노동·경비 포함 단가가 낮더라도, **유휴 고정비와 초기 투자 회수는 별도**다. 위 낮은 생산량 표본에서 제조가 자판기 증설보다 빠른 수익을 준다고 주장하지 않는다. 원작의 가격을 복사하거나 공장비를 임의로 더 낮추지 않았으며, 이 부분은 다음 수치 검토의 명시적 잔여 항목이다.

초기 자력 성장 속도·가격정책의 차이·실제 공장 운영비·직원 이동 오류까지 이번 수정 범위다. 직원과 공급망이 필요한 3대 확장 경로는 실행했지만, 모든 제조 전략이나 후반 성장 한계가 균형을 이룬 것은 아니다.

재현: `npm run test:strategies`는 현재 빌드에서 기본 365일·시드7/19473·6정책·기기상한3으로 실행한다. DAYS, SEEDS, POLICIES, MAX_MACHINES, EVENTS, SUPPLY, RESULT_FILE 환경변수로 조건을 지정한다. 전후 원자료는 당시 두 빌드 비교 결과이며 현재 스크립트가 과거 빌드를 재구성하지 않는다.
