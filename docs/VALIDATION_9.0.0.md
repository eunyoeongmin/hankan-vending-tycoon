## 실제 브라우저

Windows의 격리된 Playwright Edge로 검증했습니다. 인앱 브라우저에 사용 가능한 브라우저가 없어 대체했습니다.

- 일본어 첫 접속·새 게임, 실제 발주/배송/고용/연구 검토/공장 생산/자회사/차입/보험/계약 클릭.
- 1440×900, 800×600, 390×844, 720×450에서 문서 가로 넘침 없음. 12개 업무 화면 접근 및 일본어 화면의 한국어 혼입 검사 통과. 대표 이미지를 직접 확인.
- 정지/차입금 노드 유지 `same=true`, 관찰 중 불필요한 내용 변경 `0`, 위치 이동 `0`.
- 정지/재개, 메뉴/도움말/닫기, 저장 재개 검사 통과. 시작 화면에 닫기 버튼 없음.
- 후반 거래 경로에서는 시험용 자금과 작업 시간을 주입합니다. 정상 자금 플레이와 구분합니다.

## 최소 수정과 남은 평가

자산 이동·급여·매출 배분의 중복/누락, 이전 저장 장부 보존, 자회사 소수 지분 정산을 수정했습니다. 임금의 작은 차이만으로 조직 전체가 이탈하는 문제에 5% 허용 범위를 두고, 위임 기본 예산을 하루 $200로 설정했습니다. 본격 수치 밸런싱은 하지 않았습니다.

자동 검사는 모든 전략의 재미·공정성, 전체 기기/OS, 장시간 인간 플레이 또는 정식 회계 기준 준수를 보장하지 않습니다.
