# 4개 상권 배경 아트 방향

2026-09-11. 사용자 선택: 마지막 생성 시안의 SimCity 참고 타일 규모/선명한 제한 색상/격자 도로 방향. 더 거칠고 투박한 도트 표현을 지향한다. 이 문서는 설계이며 새 배경 적용 완료를 의미하지 않는다.

## 공통 제작 기준

- 같은 시점, 타일/층고/사람/자판기 크기, 픽셀 단위와 광원. 작은 건물 타일이 모인 도시 지도.
- 재질당 3~4단계 명암, 명확한 외곽선, 선택적 디더링. 사진 같은 재질과 무작위 노이즈를 피한다.
- 입지마다 식별 건물, 보행 접근로, 자판기 설치 여백, 직원 정차/접근 지점을 함께 설계한다.
- 배경판(지형/도로), 건물/가림 레이어, 실제 판매 기기/손님/직원, 날씨/사건 장식, UI/문자를 분리한다. 한 장에 모든 움직임을 그려 넣지 않는다.
- 현재 800:520 화면과 타일 자산의 기준 픽셀 크기를 별도로 관리. 원본 비율 유지와 확대 상한을 지킨다.
- 간판의 큰 문자/장소명은 게임 KO/JA 표시로 제공; 실제 기업 로고는 쓰지 않는다.
- 계절/사건 장식은 해당 날짜/활성 사건에 따라 표시. 행사 없는 날에도 영구 축제처럼 그리지 않는다.
- 기존 지도에 그림을 억지로 맞추지 않는다. 원화의 보도/출입구에 맞춰 표시 설치점과 표시 이동 경로를 함께 설계하되, 배송 시간/거리는 별도 검증 없이 바꾸지 않는다.

## 골목·주택가: 생활권의 혼합 상권

기와/슬레이트 지붕, 담장, 작은 아파트와 동네 점포. 회갈색·벽돌색·차분한 초록. 대학/오피스/역은 주택가 외곽에 놓아 중심 업무지구와 차별화.

| 실제 입지 | 식별 풍경 | 세부 디테일 / 기기 자리 |
|---|---|---|
| 느티나무 공원 | 큰 느티나무와 작은 동네 놀이터 | 벤치·그네·음수대, 공원 입구 |
| 한빛대학교 | 캠퍼스 정문과 낮은 강의동 | 자전거 주차·게시판·복사집, 정문 밖 |
| 센트럴 오피스 | 주거지 경계의 중소형 사무동 | 작은 주차장·도시락집, 측면 출입구 |
| 햇살 주택가 | 단독주택과 저층 공동주택 | 빨래·화분·쓰레기 수거장·골목 거울, 구멍가게 옆 |
| 한칸역 2번 출구 | 소규모 통근역 출입구 | 자전거 보관·시간표·작은 승강장, 출구 옆 |
| 강변 산책로 | 제방과 강변 보행/자전거길 | 난간·계단·벤치, 산책로 진입부 |

## 오피스 상권: 규칙적인 블록과 업무 시설

직선 보도와 넓은 교차로, 유리/콘크리트 중고층. 청회색·흰색·짙은 녹색. 건물마다 실루엣을 다르게 한다.

| 실제 입지 | 식별 풍경 | 세부 디테일 / 기기 자리 |
|---|---|---|
| 테크 타워 | 안테나/설비가 있는 기술기업 고층 | 유리 로비·통신설비, 공개공지 |
| 금융 거리 | 석재 은행과 증권사 블록 | 규칙적 가로수·택시 승강장, 보행 통로 |
| 스타트업 캠퍼스 | 개조한 낮은 사무동 여러 채 | 공유 마당·자전거 거치대, 공용 휴게공간 |
| 미디어 센터 | 방송국/스튜디오 | 위성접시·중계차 주차, 직원 출입구 |
| 야근 오피스 | 사무동과 야간 편의점 | 시간대에 맞는 켜진 창문·작은 휴게공간, 측면 통로 |
| 컨벤션 홀 | 넓은 지붕과 전시장 입구 | 하역장·행사 안내판·버스 정차구역, 방문객 대기 공간 |

## 역세권·번화가: 이동과 소비가 만나는 고밀도 상권

가장 조밀한 저중층 점포, 철도와 환승 동선, 일부 호텔/상업 고층. 빨강·파랑·노랑 간판을 제한적으로 사용.

| 실제 입지 | 식별 풍경 | 세부 디테일 / 기기 자리 |
|---|---|---|
| 중앙역 | 큰 역사와 여러 승강장 | 개찰구·열차·시계·역전 출입구 |
| 쇼핑 아케이드 | 지붕으로 연결된 상점 통로 | 어닝·진열대·셔터·골목 연결부 |
| 버스 터미널 | 여러 승차장과 회차 공간 | 버스·노선 안내·벤치, 대합실 외벽 |
| 영화의 거리 | 영화관과 식당 블록 | 포스터 케이스·매표소, 입장 대기 공간 |
| 야시장 입구 | 노점 골목의 입구 | 낮에는 접은 천막, 영업 시간에는 노점/등, 입구 공터 |
| 환승 광장 | 역·버스·상점을 잇는 보행 광장 | 횡단보도·안내도·택시 승강장, 보행을 막지 않는 가장자리 |

## 관광지·공원: 자연 지형과 목적지

해변→정원→언덕, 내륙의 호수/온천/놀이공원을 관광 순환도로로 잇는 넓은 지역 지도. 해변과 호수는 분리한다. 실제 축척의 한 블록에 여섯 시설을 몰아넣지 않는다. 청록·모래색·계절 나무색, 낮은 시설 위주.

| 실제 입지 | 식별 풍경 | 세부 디테일 / 기기 자리 |
|---|---|---|
| 해변 산책길 | 모래사장과 해안 데크 | 방파제·샤워실·파라솔, 데크 진입부 |
| 벚꽃 정원 | 산책로를 두른 벚나무 군락 | 작은 다리·정자·피크닉 공간, 정원 입구 |
| 전망대 | 고지대 전망 시설 | 계단·난간·망원경, 계단 아래 휴게공간 |
| 호수 캠핑장 | 내륙 호수와 캠핑 구획 | 텐트·취사장·주차공간, 관리동 |
| 겨울 온천길 | 온천 여관과 좁은 상점길 | 온천 표식·수증기·족욕장, 대기 공간. 사계절 영업, 겨울에 눈 강조 |
| 가족 테마파크 | 작은 관람차·회전목마·입구 | 매표소·유모차 보관·휴게 벤치, 출입구 |

## 게임과 연결할 표현 (미구현)

재고 없음/정비/판매 중 기기 외형, 실제 직원 이동과 보충, 시간대별 창문/가로등, 활성 후원·축제의 현수막/임시부스. 상권 손님 분포를 실제 게임 상태와 연결하며 장식 군중을 실제 매출로 취급하지 않는다.

## 확인한 이름 문제

골목·주택가는 코드상 공원·대학·오피스·주택·역·강변이 섞여 있다. 이름을 그대로 유지할 경우 '주택가 중심의 생활권'으로 그린다. 한칸역 입지는 한국어 '2번 출구'와 일본어 '東口'가 불일치하므로 아트 적용 시 번역을 맞춰야 한다. 이번에는 게임 데이터/번역을 수정하지 않았다.
