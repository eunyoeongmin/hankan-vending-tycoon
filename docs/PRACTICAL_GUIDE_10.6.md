# 비서와 실제 운영 실습 — 10.6.0

2026-09-14. 설명문+초상화로는 진행 방법을 가르칠 수 없다는 사용자 수정 요구를 반영한다.

## 시작과 자금

새 회사 설정의 `비서와 실습 · 연습 회사 $5,000` 또는 최초 운영 안내의 실습 시작으로 진입한다. 연습 회사의 조건을 시작 전에 공개한다: 초기 현금 $5,000, 낮은 경쟁, 사건 없음, 안정 공급, 자동 운영 끔. 선택한 회사의 자금에 몰래 보조금을 지급하지 않고 새 회사 생성 경로에 연습 조건을 전달한다. 현행 기본 현금 $350과 Koyo S80 약 $2,160의 차이 때문에 실습 첫 확장이 막히는 것을 피한다. 같은 회사로 계속 플레이할 수 있다. 자유 경영은 원래 선택한 조건을 유지한다.

## 단계와 판정

| 순서 | 직접 할 일 | 완료 근거 |
|---|---|---|
| 1 | 내 기기 선택 | 실제 지도 선택 클릭 |
| 2 | 시간 재개 | 해당 기기의 실제 누적 판매 증가 |
| 3–4 | 직접 회수 출발, 시간 진행 | 성공한 작업 등록 후 회수 작업 완료 |
| 5–6 | 탄산음료 발주, 입고 대기 | 실제 발주 작업 ID의 입고 완료 |
| 7–9 | 경로 편성, 출발, 배송 대기 | 실제 경로 생성·출발·상품을 실은 작업 완료 |
| 10 | 같은 상권의 입지 계약 | 실제 계약 성공 |
| 11–12 | Koyo S80 주문, 배송 대기 | 실제 기기 주문 ID의 배송 완료 |
| 13–14 | 설치 신청, 작업 대기 | 실제 기기 생성 및 운영 정보 초기화, 빈 재고 |
| 15 | 필요시 추가 발주, 두 기기 경로 재편성·배송 | 새 기기로 상품을 실은 실제 배송 완료 |
| 16 | 새 기기 영업 | 추가 기기의 실제 판매 발생 |

완료 시 한 단계씩 진행하고 시간을 멈춘다. 새 타이머나 별도의 가상 거래 엔진은 없다. 비서는 구매/배송 버튼을 대신 누르지 않는다. 표시 위치로 이동하는 버튼은 해당 업무 창을 열고 실제 버튼에 초점을 준다. 안내 중 지도·업무 창·시간 조작을 계속 볼 수 있다. 대기 단계에서는 사용자가 배속을 선택한다.

## 제한과 저장

기본 메뉴와 재무/알림은 유지하며, 발주→물류→기기 조달 순서로 메뉴를 연다. 관련 없는 고급 거래 버튼도 비활성화한다. 실습 중단/완료 시 제한을 푼다. 기존 회사에는 강제로 적용하지 않는다. 학습 진행과 주문 ID는 회사 저장에 포함된다. 별도 완수 버튼으로 목표를 속여서 완료할 수 없다.

## 설치 점검

외주 설치비 $5가 부족해도 설치 버튼이 켜질 수 있던 조건 차이를 수정했다. 입지 계약·입고 기기·중복 설치·점유·설치비를 확인하고 비활성 상태 및 사유를 표시한다. 원 제보자의 저장은 제공되지 않았으므로 그 제보의 원인을 확정했다고 표현하지 않는다. 직원 이동/해고 등으로 자체 설치 작업이 보류되는 경우의 복구 UI는 별도 후속 점검 대상이다.
