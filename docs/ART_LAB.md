# 거리 아트 시험판

2026-09-11. 본편과 독립된 `dist/art-lab.html`에서 확인합니다.

- 도로·보도·잔디, 상점, 자판기, 나무, 가로등, 벤치, 쓰레기통, 손님, 배송 직원, 운반차를 독립 자산으로 제작했습니다.
- 공통 24색, 정수 픽셀, 2:1 대각선 바닥 투영. 원본 화면 480×300. 표시 1/2/3배, 좁은 화면은 스크롤하며 비율을 유지합니다.
- 손님·배송 직원은 4방향 × 4걷기 프레임과 작업 자세가 있습니다. 건물 144×155, 자판기 20×34, 사람 17×25 픽셀입니다.
- 구매: 이동 → 구매 → 재고 1 감소 / 매출 $1.50 → 퇴장. 보충: 이동 → 작업 → 창고에서 최대 12개까지 이전 → 퇴장.
- 자동 시작 없음. 구매/보충 중 재입력 차단, 일시정지, 초기화, 한국어/일본어, 개별 자산 보기 제공.
- 모든 자산은 새로 작성한 픽셀 도형입니다. 생성한 상권 PNG를 배경으로 깔거나 잘라 사용하지 않습니다.
- 본편 저장·경영 시간·경제 수치와 연결하지 않은 동작 시안입니다. 본편 10.4.0 HTML은 변경되지 않았습니다.

## 검증과 남은 범위

`tests/browser-art-lab.cjs`: 구매·보충 1회 반영, 일시정지, 초기화, 한국어/일본어, 네 화면 너비의 정수 배율, 자산 전체의 팔레트/불투명 픽셀, 브라우저 오류 검사. 실제 화면 캡처로 구매·보충 자세를 확인합니다.

현재는 한 상점의 통일감 검토용입니다. 4상권/24입지의 자산 다양화, 계절·날씨 변형, 다수 인물 이동과 가림 처리는 본편 적용 전에 남아 있습니다. 2026-09-11 사용자 승인 완료. 본편 적용 현황은 [10.5 기록](PIXEL_CITY_10.5.md) 참조. 레퍼런스 수준의 도시 밀도·디테일을 달성했다는 의미가 아닙니다.
