# 10.1.0 UI 개편 검증

2026-09-11. Windows 95 색상/회색 입체 조작부/단색 제목 표시줄을 참고한 고정형 업무 화면.

## 구현

- `office.js`의 메뉴별 지도 숨김을 제거하고 reference/management 화면도 업무 패널만 전환한다.
- `desktop.js`는 기존 도시와 업무 영역을 유지하며 제목 표시줄과 하단 작업 버튼을 추가한다. 시뮬레이션 타이머를 추가하지 않는다.
- 업무 창 상태는 open/minimized/closed. 최소화는 내용과 입력값을 보존하고 작업 버튼으로 복원한다. 닫기는 작업 버튼도 숨기지만 회사 메뉴에서 다시 열 수 있다.
- 한국어/일본어 제목·접근성 이름을 제공한다. 시작 화면에 닫기 버튼을 추가하지 않는다.
- `desktop.css`는 모든 업무 화면에 동일한 창 배치를 적용한다. 작은 화면은 상단 도시/하단 업무, 넓은 화면은 좌측 도시/우측 업무 창이다.
- 기존 그림/사람/계절 표현은 유지한다. 자유 이동하는 창 관리자나 픽셀 아트 교체는 구현 범위가 아니다.

## 검증

- `python build.py` 성공.
- `npm test`: 기존 19묶음 통과. workspace 검사에 최소화 중 갱신·복원·닫기·재진입과 정지 상태 유지 추가.
- `npm run test:browser`: 기존 5묶음 통과 (추가 전 명령). 실제 Edge/Playwright에서 영업·발주·생산·금융·메뉴·KO/JA·저장·시계·노드 안정성 확인.
- `node tests/browser-desktop.cjs`: 전체 KO/JA 업무 메뉴에서 동일 도시 노드, 화면 중앙 hit test로 가림 없음, 최소화/닫기/복원/입력값 보존/키보드와 4개 화면 크기 확인. 이 검사를 test:browser에 추가.
- 1440×900, 390×844 스크린샷 시각 확인: 도시와 업무 창 모두 노출, 테두리·작업 표시줄·표·입력칸 확인. 800×600과 720×450도 동작/가로 넘침 검사 및 이미지 생성.
- 장시간 인간 플레이나 난이도 밸런싱 검증은 수행하지 않았다. 이번 변경은 경제 규칙을 바꾸지 않는다.

## 공개 반영

배포 후 실제 결과를 기록한다. 로컬 검증 시점의 공개 버전은 10.0.0 / Sites 21.
