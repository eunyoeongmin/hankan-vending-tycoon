# 10.3.0 사건 개편 검사

2026-09-11. 구현 범위는 [40종 사건 대조](EVENT_AUDIT.md).

## 자동 검사 · 로컬 통과

- `npm test`: 기존 20묶음 + 사건 1묶음. 40종 × 2선택 및 각 선택 전 저장 재개, 지연 결과, 중복 결제, 자금 부족, 기한 만료, 경쟁사 자금, 오류 저장을 검사한다.
- 추가 경계: 실제 변동 차입 금리 변경, 기존 고정 계약 제외, 정비 접수 시 중지 유지·완료 시 해제, 도매 운송 중 배치 회수·보상, 수령 창고 부족 시 무거래.
- `npm run test:balance`: 기존 6묶음(3난수 × 731일 장기 경영 포함) + 사건 장기 1묶음. 사건 장기 표본은 추가 자금으로 자연 발생/보류/선택을 섞어 2난수 × 365일 실행한다.
- 신규 장기 표본: seed 7 / 19473 모두 366일 도달, 사건 각 38건 처리, 판매 25,522 / 27,338개. 재고 배치 보존·현금 장부 대조, 반복 결정/정지 없음. 이는 수치 난도/재미 보증이 아니다.

장기 경영 검사도 선택 불가 시 보류하도록 보강하고, 3난수 모두 실제 732일 도달을 확인했다. 선택을 처리하지 못한 채 같은 날짜에서 검사 반복만 완료하는 경우를 성공으로 인정하지 않는다.

## 실제 브라우저 자동 조작

로컬 격리 Edge/Playwright에서 `browser-business-events`, `browser-management`, `browser-desktop` 검사 통과. 사건 실제 선택 비용·샘플, 결과 기록, KO/JA, 보류 저장 재개, 보류 상태 실제 시계, 정지·차입금 DOM 안정성, Win95 업무 창·도시 유지, 네 화면 크기를 확인했다. 사람이 장시간 플레이한 검증은 아니다.

## 공개 반영

로컬 최종 회귀 통과. 공개 버전·배포 결과·소스 검사 링크는 배포 후 이 절과 DEVELOPMENT.md에 기록한다.

## 남은 부분

인간 플레이를 통한 발생 간격·비용/수익·미대응 난도 조정은 미완료. 과거 저장에 이미 혼합된 배치의 원래 제조 계보는 복원하지 않는다. 구 규칙의 이미 선택된 사건을 소급 재실행하지 않는다.
