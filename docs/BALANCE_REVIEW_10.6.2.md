# 10.6.2 초반 운영·실습 밸런스 검토

검토일: 2026-09-14. 밸런스 담당 에이전트의 독립 검토. 게임 수치는 변경하지 않았다. 기준은 작업 시작 시 빌드된 10.6.1이며, 이번 대화 연출 변경의 최종 회귀 검사와는 구분한다.

## 판단

기본 실습의 자금 부족이나 정상 구매→설치 경로의 진행 불가는 이번 표본에서 재현되지 않았다. 가장 큰 문제는 **시간 조작을 익히기 전 대기 구간이 길고, 실습 순서상 품절 상태가 오래 이어진다는 점**이다. 지금은 기기 가격이나 전체 게임 날짜를 줄이기보다, 첫 대기에서 시간·배속·작업 완료를 설명하고 안내 중인 상태를 이해시키는 것이 우선이다.

## 검토 방법

- `tests/management-harness.cjs`의 jsdom 환경에서 기존 `tests/practical-guide.cjs` 실제 거래 흐름을 그대로 실행했다. 대기 반복 횟수, 현금, 첫 기기 재고를 추가 출력했으며 게임 소스나 테스트 파일은 수정하지 않았다.
- 기존 검사와 동일하게 저장 후 입고 단계 재개, 설치비 부족 거절, 중복 설치 거절, 새 기기 실제 판매, 실습 잠금 해제를 통과했다.
- 첫 판매는 엔진 200ms 간격으로 별도 표본 3개(seed 7, 19473, 42)를 관찰했다. 브라우저 화면이나 실제 사람의 대기 시간을 측정한 것은 아니다.
- 내부 1일 `DAY_MS=24000`, 실제 1배속 1일 `REAL_DAY_MS=180000`이므로 엔진 시간에 7.5를 곱해 벽시계 시간을 환산했다. 전 과정 측정은 1000ms 간격이고 일 경계의 남은 시간 처리 때문에 아래 수치는 근삿값이다.

## 대기 시간

| 구간 | 1배속 환산 대기 | 관찰 |
|---|---:|---|
| 첫 판매 | 정밀 표본 39초; 전체 흐름 표본 45초 | 3개 seed 모두 39초까지 판매 발생. 보장된 고정 판매 시점은 아님 |
| 직접 매출 회수 | 약 45초 | 완료 시 첫 재고 60개가 모두 판매됨 |
| Aqua 음료 200개 입고 | 약 7분 15초 | 물류 직원 0. 기본 주문 1.8일에 마지막 하역 구간 처리율 0.25가 적용됨 |
| 첫 경로 배송 | 약 15초 | 기존 기기에 80개 보충 |
| Koyo 기기 배송 | 6분 | 실제 계약 2일 |
| 외주 설치 | 3분 | 실제 작업 1일 |
| 새 기기 보충 | 약 30초 | 실제 화물 경로 완료 |
| 새 기기 첫 판매 | 약 15초 | 완료 및 제한 해제 |

전체 흐름 표본의 대기 합은 약 **18분 45초**이고, 설명 읽기·메뉴 조작 시간은 추가된다. 단계 완료마다 1배속으로 복귀하므로 한 번 배속을 올렸다고 이후 대기도 빨라지지는 않는다. 첫 판매 대기는 가짜 진행률보다 영업 시작·손님 구매·재고/매출 변화를 보여주는 것이 적합하다. 주문·설치는 실제 잔여 시간에 맞춰 안내해야 한다.

## 현금과 출점 비용

| 항목 | 금액 / 결과 |
|---|---:|
| 표준 자유 경영 초기 현금 | $350 |
| 입문 자유 경영 초기 현금 | $750 |
| 실습 회사 초기 현금 | $5,000 |
| 실습의 추가 입지 계약 | $63 (`햇살 주택가`, 입지 기준 $180 × 35%) |
| Koyo S80 신규 구매 | $2,160 |
| 외주 설치 | $5 |
| 입지+신규 기기+설치 합 | $2,228, 재고·운영비 제외 |
| 실습 입고 완료 시 현금 | $5,012.843 |
| 실습 기기 배송 완료 시 현금 | $2,785.693 |
| 실습 전체 완료 시 현금 | $2,895.243, 2대 운영 |

표시 전 내부 정밀도이며 화면은 소수 둘째 자리로 반올림한다. 현금 변화에는 매출 회수와 실제 운영비가 포함되므로 전부 순이익은 아니다. 실습은 충분한 출점 자금을 준 상태에서 조달 절차를 배우는 조건이다. 표준 자금은 새 기기 단품 가격의 약 16.2%이므로 실습과 동일한 즉시 출점을 기대하게 만들면 안 된다. 수익 재투자·금융을 통한 자유 경영의 출점 속도는 별도의 장기 플레이 검증이 필요하다.

## 후속 검토 대상과 최소 대응

1. **긴 대기의 목적을 먼저 설명:** 인사 후 어떤 회사를 맡았는지, 초기 기기·재고·현금, 안내 중 시간 정지, 재개와 배속 사용을 순서대로 알려 준다. 실습 전체 기간을 가짜로 줄이지 않는다.
2. **품절 상황을 실패로 오해하지 않게 안내:** 표본에서 회수 완료부터 약 2.4일의 입고 대기 동안 기기는 빈 상태였다. 첫 배송 이후 기기 주문/설치 대기 중에도 첫 기기 재고가 소진됐다. 이번 입문 실습이 구매·배송 순서를 배우는 구간임을 설명하고, 완료 때 재주문 시점/품절 대응의 후속 학습으로 연결할 필요가 있다. 정상 운영에서 품절 방치가 권장 전략이라는 인상을 피한다.
3. **자금 조건 차이를 명확히 유지:** $5,000 연습 회사는 별도 시작 조건이며 표준 난이도를 보정한 결과가 아니다. 튜토리얼 완료 후 같은 회사로 계속할 수 있다는 점도 알려 준다.
4. **설치 장애는 범위를 제한해 기록:** 정상 흐름과 설치비/중복 요청 검사는 통과했다. 최초 사용자 저장의 설치 불가 원인은 미확정이다. 자체 기술 인력을 설치 도중 재배치·교육·해고하면 작업 처리율이 낮아지거나 멈추는 상태의 UI/복구 검토는 남아 있다.
