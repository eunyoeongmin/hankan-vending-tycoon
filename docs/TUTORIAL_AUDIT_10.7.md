# Narrative Designer: 전체 경영 과정의 안내 점검 (10.7)

2026-09-14. 범위는 시작부터 위기·후반 목표·계속 경영까지다. 이번 수정은 **상황별 업무 상담**이며 심화 시스템의 실제 조작 실습 완성을 뜻하지 않는다. Game Designer 통합 담당이 은행/Economy 및 화면/Level 결과와 연결한다.

## 관찰과 변경

기존 16단계는 실제 거래·입고·배송·설치·판매로 진행되지만 완료 이후 새로운 업무를 다시 물어볼 공통 창구가 없었다. 기존 경영 분석의 운영 순서와 진단은 유용하지만 해당 화면을 이미 아는 사용자만 찾기 쉬웠다.

`src/operating-advisor.js`와 CSS에 업무 창의 **비서에게 질문 / 秘書に相談**을 추가했다. 누르면 현재 업무의 짧은 대화, 실제 현황, 관련 업무로 이동하는 버튼이 나온다. 일반 화면에서 자동 팝업은 띄우지 않으며, 같은 갱신에서는 버튼을 유지한다. 대화 중 영업이 계속된다는 문구와 수동 정지 위치를 표시한다. 새 타이머나 경제 거래, 학습 완료 플래그를 만들지 않는다. 16단계 실습 중에는 숨겨 기존 강제 학습·강조막과 중첩하지 않는다.

## 검증 근거

- `tests/operating-advisor.cjs`: 11개 업무의 상담·연결 경로, KO/JA, 동일 상태 갱신의 버튼 동일성, 상담의 현금/날짜/정지 상태 불변, 기존 기본 실습에서 숨김을 검사한다.
- 통합 전 기존 빌드에 새 스크립트를 주입한 독립 jsdom 검사 통과. 최종 빌드·브라우저 화면·공개 반영은 통합 담당의 별도 기록을 따른다.
- 상담 열기/닫기 상태는 화면 상태로만 유지하며 저장 구조를 변경하지 않는다. 새로 접속하면 다시 질문 버튼으로 연다.
- 이 결과는 인간 신규 플레이 테스트, 경제 수치의 적정성, 모든 시스템의 행동형 튜토리얼 완성을 증명하지 않는다.
