# 10.2.0 도시 그래픽 검사

2026-09-11. 도시 장면의 그래픽을 Windows 95 업무 UI와 통일.

- `city-art.js/css`: 5상권, 4계절, 건물·도로·나무·기계·손님·직원·날씨/판매 표시와 별도 지도 상태줄. SVG로 작성해 외부 이미지 의존성 없음.
- 기존 입지/이동 경로 좌표와 구매 기록을 사용. 배경은 상권/계절/언어가 변경될 때만 갱신. 경제·저장 규칙 변경 없음.
- `base.html`: 기존 기계/날씨 그리기에서 새 그래픽 함수를 호출. 중복 기계 레이어 생성 방지.
- `python build.py`, `npm test` 19묶음 통과.
- 기존 `test:browser` 6묶음 통과: 4화면, 실제 조작/저장/구매/운영/시계, 기존 버튼 노드 변동/호버 이동 없음.
- `browser-city-art.cjs` 통과: 5상권×4계절×한국어/일본어, 동일 도시 DOM, 비/눈, 움직임 끄기, 핀의 실제 마우스 클릭, 모바일 시간/계절 줄 및 가로 넘침 없음. 해당 검사를 test:browser에 추가.
- 신규 검사 초기의 비활성 항구 인덱스가 다음 언어 변경까지 남는 테스트 설정 오류 수정: 그래픽 표본을 읽은 직후 원래 상권으로 복구. 게임 동작 오류로 판정하지 않음.
- 데스크톱 봄/눈, 모바일 및 1440×900/390×844 화면 이미지 확인. 기존 화면 검사는 800×600/720×450도 포함.
- 장기 인간 플레이나 경제 수치 밸런싱은 이번 그래픽 검사 범위가 아님.

공개 반영 결과는 배포 후 기록한다.
