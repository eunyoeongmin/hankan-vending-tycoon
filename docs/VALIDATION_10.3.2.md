# 10.3.2 운영 설정·안내 검사

2026-09-11. 숫자 밸런스 재조정 없이 기존 동작의 선택권과 안내를 수정했다.

## 구현

- `mgStartOptions`: 신규 회사에서만 적용. 세 선택 기본 false. 저장 로드 시 덮어쓰지 않는다. 경쟁사 설정을 바꾸지 않는다.
- 자동 운영: 발주/경로 배송/정비/등록된 계속 생산/가격 정책. 연구 단계 승인도 자동 운영 중에만 작동하며 선납 예산 안에서 진행. 추가 비용 승인 별도.
- 중단은 새로운 자동 작업만 막는다. 이미 계약한 주문·이동과 계약 지급을 취소하지 않는다.
- 누적 사건 처리 수는 `state.eventsResolved`: 기간 만료 포함, 대상 소멸에 따른 취소 제외. 결과 기록 120개 제한과 독립.
- 별도 추천 AI 없이 기존 튜토리얼 6단계·도움말·운영 규정의 수동 보충 안내를 고쳤다. 구형 매일 급여/외부 상품 연구 해금 안내를 현행 규칙으로 교체했다.

## 검사

- 기존 npm test 22묶음 통과; 신규 tests/onboarding.cjs 통과.
- npm run test:balance 7묶음 통과. 731일 자동 영업 3난수, 365일 자연 사건 2난수 포함. 기존 자동 운영 검증용 fixture는 명시적으로 자동화를 켠다. 이 결과는 수동 기본값 방치의 생존 검사가 아니다.
- 신규 브라우저 검사: KO/JA, 세 선택 기본 끔, 일시정지 시작, 실제 자동 운영 토글, 저장 후 설정 유지, 상태/시계 노드와 마우스 위치 안정성. 390/1440 화면의 시작 메뉴 스크린샷을 생성하고 일본어 모바일 화면을 직접 확인했다.
- npm run test:browser 10묶음 통과. KO/JA, 기존 4화면, 정책/재무/제조/이벤트 실제 클릭과 안정성 검사 유지.
- 첫 튜토리얼 제안과 6개 안내의 KO/JA 내용, 즉시 진행을 선택한 시작도 별도 검사.
- 공개 배포 최종 결과는 완료 후 갱신한다.

## 남은 밸런스

- 기본 1대 영업의 장기 현금 축적, 고용/공장 확장 투자 회수, 이벤트 비용·효과·미대응 편차는 아직 수치 조정 전이다.
- 이번 신규 기본값을 실제 초보자가 이해하고 수동 보충하는지 인간 플레이로 평가하지 않았다.
- 10.3.1의 14개 반년 정책 비교를 유지하며, 이번에 새 비교 결과를 생성한 것으로 취급하지 않는다.
