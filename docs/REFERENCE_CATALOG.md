| U4 | 반복 업무 관리 | 저장한 운영 규정·다중 선택·공급처 일괄 변경·예산 승인 한도·예외 보고 |
| U5 | 다양한 경영 목표 | 외부 조달 전문·제조 공급·고급 브랜드·지역 점유·회생 등 서로 다른 성공 경로와 단계별 학습 |

## 적용 순서와 완료 기준

1. 독립 사업장/처리량/손익(L1·H1·B2·U1)을 먼저 연결한다. 인력·재고·설비의 소속과 비용 귀속을 확정해야 한다.
2. 물류·기기 수명·입점 계약(L2~L5·V1~V4·C1~C4)을 연결해 확장의 비용과 중단 원인을 만든다.
3. 상품/브랜드·공급 회사·공장·연구(M·P·S·F·R)를 연결해 서로 다른 성장 전략을 만든다.
4. 경쟁 AI는 각 신규 규칙과 함께 확장한다. 모든 경제 규칙을 끝내고 마지막에 AI를 덧붙이지 않는다.
5. 후기 재무·지배구조(B4~B5·G)를 넣는다. 대규모 조직 위임과 정보 화면은 해당 단계마다 같이 구현한다.
6. 도시·시대는 원인이 경제에 반영되는 범위부터, 고급 옵션은 난이도에 따라 단계적으로 노출한다.
7. 핵심 연결 후 본격 수치 밸런싱. 안정 운영·공격적 확장·제조·인수가 각각 비용과 위험을 갖는지 실제 초기 자금으로 검증한다.

후보마다 대안/비용/시간/실물 자원/정보 화면/AI 대응/저장/검사 기준이 필요하다. 공급 독점은 유료 약정·유한 물량·계약 기간이 있어야 하며 상대와 플레이어 모두에게 대응 경로를 제공한다. 자판기 몇 대로 도시 전체 경기가 움직이지 않도록 규모를 반영한다. 같은 전략의 반복 클릭을 늘리는 기능은 재설계한다.

## 현재 우선순위에서 제외하거나 조건부로 둘 것

- 은행·보험사를 직접 창업해 운영: 금융은 우선 자판기 회사가 사용하는 서비스로 제한.
- 시장/정당/도시 행정 직접 운영: 도시 변화는 사업 환경으로 반영.
- 광산·농장·자동차·소프트웨어 등 무관 산업의 전면 확대: 음료/기기 공급과 직접 관련된 범위 우선.
- 사무실 가구 배치·인물 생활 세부 시뮬레이션: 팀의 비용과 업무에 필요한 정도만 도입.
- 불법 공작·버튼 한 번으로 상대 파괴: 공급·가격·서비스·인재·입지·자금 경쟁에 집중.
- 30개 운영 경쟁사·무한 맵·멀티플레이: 현재 HTML 게임의 UI·성능·저장/동기화 검증과 별도 투자 없이는 확대하지 않음.
- 모든 기업집단/금융 기능을 창업 첫날 노출: 성장 단계·난이도에 맞춰 제공.
