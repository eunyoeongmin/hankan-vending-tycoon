# 공급 산업·연구·직원 개편 설계

2026-09-10 사용자 설명 및 기존 기획 원문 대조. **이 파일은 설계이며 구현 완료 기록이 아닙니다.** 현재 공개 게임은 버전 16 / 소스 7.0.0입니다.

## 사용자 의도와 기존 기획

기존 기획에도 음료 제조사·자판기 제조사·벤딩 오퍼레이터의 세 축과 다음 성장이 명시되어 있었습니다. [보존 원문](DEVELOPMENT_HISTORY_2026-09-10.md)의 ‘발주/업그레이드 시스템 개편 — 수직계열화’ 참조.

1. 초반에는 음료 회사에 발주하고 자판기 회사에서 기계를 구매해 배치한다.
2. 성장하면서 협력사에 투자한다. 연구는 즉시 완료되지 않고 시간이 지난 뒤 성과가 나온다.
3. 자금과 사업 규모가 커진 뒤 직접 공장을 설립하고 운영한다.
4. 직원 운영도 이 경제 구조에 영향을 주어야 한다.

현재의 즉시 레벨 연구, 입지 구매와 기기 생성의 결합, 현금으로 여는 생산 라인, 회수/보충 인원 카운터는 위 구조를 충분히 구현하지 못합니다. 기존 자동 검사는 이 단순한 구현의 정상 동작만 검사했으므로 기획 완료 판정은 철회합니다.

## 구현할 거래 구조

### 외부 조달과 벤딩 운영

- 음료 제조사는 회사별 브랜드·상품·품질·생산 여력·납기·공급 조건을 가진다. 공급처 선택은 배송 속도 프리셋 선택을 넘어 실제 회사와의 거래가 된다.
- 기기 제조사는 모델별 구매 가격·용량·지원 상품/온도·소비전력·고장/수리 특성을 가진다.
- 기계 구매 주문 → 제작/배송 → 보유 미설치 기기 → 입지 계약과 설치를 분리한다. 입지 클릭만으로 기기를 생성하지 않는다. 입지 입찰 또한 기계 제조 구매를 우회하지 않는다.
- 플레이어는 재고, 설치 위치, 가격, 직원과 현금흐름을 운영하는 벤딩 회사로 출발한다. 외부 조달만으로 계속 경영할 수 있어야 한다.

### 협력사 투자와 기간형 연구

- 주식 매입과 연구 투자 계약을 분리한다. 장내 주식 매입은 매도자에게 지급되며 자동으로 제조사 연구비가 되지 않는다.
- 협력사와 목표가 정해진 프로젝트를 계약하고 개발비를 투입한다. 예: 음료 신제품/품질, 기기 냉각/전력/신뢰성, 공급 생산 공정.
- 투자 즉시 보상을 주지 않는다. 계약 → 예산 집행·연구 → 시제품/검증 → 성과 적용 단계를 기존 게임 시계로 처리한다.
- 예산, 배정 연구 인력, 기술 수준, 개발 난도에 따라 예상 기간과 진척이 달라진다. 지연/추가 비용의 이유와 진행 상태를 플레이어가 확인할 수 있게 한다.
- 성과는 새 상품·기기 모델·공정 개선으로 나타난다. 기존 재고나 설치 기기를 일괄 마법처럼 개선하지 않는다. 신형 구매, 교체/개조 또는 이후 생산분에 적용한다.
- 성과 소유권, 이용 허가, 우선 공급, 기간 독점은 투자 계약 조건으로 표현한다. 경쟁사도 같은 제조사를 이용하거나 투자할 수 있으며 독점에는 실제 계약 비용·기간이 따른다.

### 직접 제조 진출

- 자체 공장은 부지/설비 자금, 건설 기간, 기술 사용권, 원재료, 작업자와 유지비가 필요한 사업장이다.
- 작업자·설비·자재 중 하나가 부족하면 실제 생산량이 제한된다. 공장 가격을 지불했다는 이유만으로 무인 생산이 되지 않는다.
- 공장 생산 → 완제품 창고 → 배송 → 자판기 판매를 연결한다. 자체 생산과 외부 발주를 병행할 수 있다.
- 공장 가동률, 실제 단위 원가, 고정비, 품질, 재고와 공급 안정성으로 직접 제조의 이득을 판단한다. 자체 공장이 자동으로 외부 조달보다 유리하지 않도록 이후 밸런싱한다.
- 경쟁사의 제조 진출, 외부 공급 계약, 기술 투자 및 기업 인수도 동일 자원/시간 규칙을 사용한다.

## 직원 시스템의 구현 방향

다음은 사용자 요구를 충족하기 위한 구현 설계이며, 모든 직원을 수동으로 클릭하는 방식은 피하고 팀·사업장 단위 관리가 기본이다.

| 업무 | 실제 경제 연결 |
|---|---|
| 보충·매출 회수 | 담당 구역, 이동 시간, 처리량, 미처리 업무와 품절/현금 회수 지연 |
| 정비 | 예방 정비/고장 수리의 대기열과 처리 시간, 담당 기술과 부품 |
| 물류 | 창고 처리와 출고 능력, 공급·공장·현장 사이 운송 |
| 공장 운영 | 배정 인원·숙련도·가동 시간에 따른 생산량/품질/인건비 |
| 연구 | 외부 협력사 또는 자체 연구팀의 실제 프로젝트 진행 능력 |

- 직무, 급여, 숙련도, 담당 팀/사업장, 처리 가능한 업무량을 둔다.
- 교육은 비용과 시간을 소비하고 이후 처리 능력을 개선한다. 채용/배치도 업무를 즉시 무한 처리하는 효과가 되지 않게 한다.
- 결원과 과부하가 납기·정비·생산·연구에 미치는 영향을 보여준다. 회사가 커지면 관리자/운영 규정으로 반복 배치를 위임할 수 있게 한다.
- 직원 수만 늘리면 모든 능력이 동일하게 상승하는 공통 버프를 피한다. 투자 판단의 대상은 업무 병목과 사업장 성과다.

## 순서와 완료 조건

- [ ] 음료/기기 제조사를 분리한 외부 조달, 기기 주문·배송·설치 및 입지 계약 분리.
- [ ] 협력사 연구 계약, 기간·인력·예산 진척, 성과의 상품/모델/공정 및 이용권 연결. 즉시 연구 경로 제거.
- [ ] 직무/사업장 인력과 실제 업무 대기열·처리량·급여·교육 연결.
- [ ] 자체 공장 건설·설비·인력·자재·생산·유통·회계 연결.
- [ ] NPC가 같은 조달/투자/생산 규칙으로 경쟁하고 공급·기술 독점 계약의 영향을 실제로 받음.
- [ ] 기존 기기/재고/연구/공장/직원 저장의 명시적 이전 및 백업. 기존 자산을 삭제하거나 새 기기를 중복 지급하지 않음.
- [ ] 한국어/일본어, 단일 시계, 안정적인 고정 UI 유지. 주문/투자/성과/생산이 저장 재개 후 정확히 한 번 반영됨.
- [ ] 초반 외부 조달, 중반 협력사 투자, 후반 직접 제조를 각각 실제 플레이와 연결 검사로 검증한 뒤 기획 완료 판정.

본격 수치 밸런싱은 이 구조를 연결한 다음 진행한다. 구현 과정에서는 진행 불가·자산 복제·무료 무한 생산 같은 치명적 문제만 우선 수정한다.
