# 10.7 전체 경제 점검 · Economy Designer

2026-09-14. [역할 지침](../game-agent.md/economy-designer.md), [전체 설계 지침](../game-agent.md/game-designer.md), [담당 운영 규정](QUALITY_ROLES.md)을 기준으로 조사했다. 경제 전 영역을 대조하되, 각 영역의 검사 기간과 미검증 항목을 구분한다. 공개 반영·종료 UI 검증은 통합 담당 기록을 따른다.

## 수정한 오류

### ECON-01 · 은행/위기/후반 · 회복 가능액에서 현대 채무 누락

- **관찰:** 기존 `companyRecoverable`은 구형 `f.bank.arrears`, 만기 지난 `f.bank.principal`만 차감했다. 10.0 이후 실제 차입은 `refFirm(f).notes`, 세금·급여·미납이자·공급대금은 `bills`에 있다. 이들이 회복 가능액에서 빠져 만기채무가 자산을 초과해도 회복 수단이 남은 것으로 계산됐다.
- **분류/영향:** 기능 오류. 플레이어 및 경쟁사의 7일 자금난 후 파산 판정에 잘못된 양수 금액을 전달한다. 통합 담당의 현대 종료 판정에서 이 값을 사용하는 연결도 필요하다.
- **최소 수정:** `mgPayableNow(f)`가 지급일이 오늘 또는 과거인 청구서와 현재 지급 원금을 합산한다. 만기에는 잔여 원금 전체, 만기 전에는 미지급 분할 원금만 포함한다. 같은 원금을 이중 차감하지 않는다. `companyRecoverable`의 기존 자산 추정은 유지하면서 구형 채무 차감을 현대 값으로 대체한다.
- **미래 채무:** 아직 지급일이 오지 않은 이자·급여 청구서나 미래 원금 전체를 즉시 차감하지 않는다. 장기 대출이 있다는 이유로 성급히 회사를 청산하지 않는다.
- **검증:** 현대 청구서 $50, 분할 원금 $30은 기준 회복액에서 $80 감소. 해당 원금 $200의 만기가 오면 청구서 포함 $250 감소. $10,000 만기 원금은 유한 회복액을 초과하며 음수 판정. 저장 후 채무 잔존도 확인. 기존 24개월 상환 검사는 별도로 통과.

### ECON-02 · 은행/위기 · 실행 불가능한 대출을 회복 자금으로 표시

- **관찰:** `companyBorrowRoom`은 신용한도만 반환했고, 실제 `mgBorrow`의 유한 은행 잔고 및 최소 차입 $10을 반영하지 않았다.
- **분류/영향:** 기능 오류. 은행 잔고가 $9.999여서 대출을 실행할 수 없어도 회복 자금이 있다고 표시할 수 있었다.
- **수정:** 추가 차입액을 신용 잔여 한도와 실제 `bankCash` 중 작은 값으로 제한하고, 최소 차입액보다 작으면 0으로 반환한다. 종료 상태도 0이다. 회사채 투자자 풀과 일반 은행 풀은 구분한 기존 계약을 유지한다.
- **검증:** 은행 잔고 9,999 내부 단위에서는 가능액 0, $10 차입 거절. 잔고 12,345에서는 그만큼 실제 차입 성공 후 은행 잔고와 추가 가능액 모두 0.

변경 파일은 `src/management-finance.js`, 신규 검사 `tests/economy-audit.cjs`다. 신규 자금 보조, 금리 인하, 기기 가격·수요·급여 일괄 조정은 하지 않았다.

## 금리·기간·현금흐름 대조

현행 게임 수치의 기록이며 현실 금융 상품을 권고하거나 현실 금리 적정성을 주장하는 내용이 아니다.

| 항목 | 코드상의 조건 | 검증/한계 |

| 금액 단위 | 내부 1,000 = $1 | 차입·은행 풀·원금 상환 보존 확인 |
| 연 금리 | `(4.5% + (100-신용)×0.1% + 상품 가산) × 도시 금리 배율`, 4~20% 제한 | 계약에 일 이율 `연율/365` 저장. 운전자금 1.5%p, 회사채 2.5%p 가산 |

## 실행 결과

모두 로컬 jsdom 자동 검사다. 실제 게임 엔진을 가속했고 화면 렌더·저장 일부를 생략한 장기 표본도 있다. 인간 플레이, 실제 브라우저 전체 플레이, 공개 반영 검증으로 표현하지 않는다.

- `tests/economy-audit.cjs`: PASS. 회복/은행/저장 검사 및 초기 현금 0에 운전자금 **$50**을 실제 차입한 뒤 자동 발주·배송·판매·회수로 3개월 만기 완납. 101일 현금 **$8,426.68**, 판매 9,354개, 차입 원금 0, 당일 지급액 0. 초기 재고 60개 이후에도 영업이 이어졌음을 확인. 자동 운영·승인 켬, 공급 지연/사건 없음, 초기 RNG는 harness 기본값. 이 실험은 영업자금 차입 회복의 한 경로이지 설비 차입 수익률 측정이 아니다.
- `tests/management-contracts.cjs`: PASS. 이전 계약 보존/저장, 설비 24개월 전 기간 상환, 이자 보존, 미납 후 현금 확보에 따른 상환.
- `tests/management-production.cjs`: PASS. 40일간 원재료 자동 매입, 관리자/직원 조건, 반복 제조, 운송 후 판매, AI 제조 및 직원 교육 중 생산 정지. $30,000와 기술 1단계를 설정한 시설 운영 검사이며 초기 자력 성장 검사가 아니다.
- `tests/reference-decisions.cjs`: PASS. FEFO·유한 채용·교대/초과근무·연구 검토/취소·OEM/도매 외상·자회사/지분·생산·실제 임대 수익 분배. **이전 Reference 모드** 기능 검사이고 현대 장기 연구의 기간 검증을 대신하지 않는다.
- `tests/business-events-long.cjs`: PASS. 초기 현금 $5,000, 자동 운영/승인, 사건 빈도 3·공급 1. seed 7은 366일/처리 43건/판매 27,345개, seed 19473은 366일/42건/26,307개. 선택 가능한 첫 선택 또는 날짜에 따른 보류 정책을 사용했다.

`tests/management.cjs`는 표준 초기 자금, 자동 운영/승인, 기본 단일 기기 정책을 731일 실행했다. 사업 자금이나 재고를 매일 추가하지 않았다. seed 7/19473은 사건·공급 지연 없음, 731293은 사건 빈도 3/공급 지연 2다. 재고 보존, 일 장부 회계식, 저장 재개를 검사했다.
