# 10.5 공통 도트 도시 적용

2026-09-11. 사용자가 독립 거리 시험판을 승인하여 같은 픽셀 자산을 본편의 기본 도시 표현으로 적용했다.

## 구현

- `src/art-lab/assets.js`의 승인된 원본 팔레트·도형·인물·상점·자판기를 본편에서도 사용한다. 추가 시설은 `pixel-district-assets.js`, 지도/작업 연결은 `pixel-city.js`에 있다.
- 기본 4상권 24입지와 확장 항만의 6입지에 각각 시설을 배치했다. 공원/대학/주택/역/강변, 타워/은행/방송국/전시장, 역사/아케이드/터미널/영화관/야시장/광장, 해안/정원/전망대/캠핑장/온천/관람차, 항만역/창고/청사/수변/터미널/주거 타워를 구분한다. 항만의 기존 개방 조건은 바꾸지 않는다.
- 새 건물/나무/인물/기기를 발밑 위치 순서로 그린다. 그림 크기를 서로 다르게 늘리지 않는다. 원본 지도 704×480. 전체 보기는 비율을 유지하며 축소하고, 확대는 1/2/3배 정수 배율 및 지도 내부 스크롤이다. 좁은 지도는 입지 번호/접근성 이름을 제공한다.
- 계절별 나무와 지면, 겨울 지붕, 비/눈/낙엽, 저녁 창문을 표현한다. 야시장 천막은 저녁에만 열린다. 해안은 화면 밖으로 이어지고 캠핑장의 호수는 독립되어 있다.
- 실제 회사별 기기/재고를 표시하고, 빈 재고/정비 필요 상태를 구별한다. 실제 구매 기록의 가격만 매출 말풍선에 사용한다. 장식 보행자는 매출을 생성하지 않는다.
- 기존 개별 보충/회수 작업과 새 배송 경로의 현재 구간을 작업자에 연결한다. 배송 경로 전체를 동시에 여러 직원으로 그리지 않는다. 회수 직원에게는 운반차를 붙이지 않는다.
- 기존 단일 장면 시계에서 그리기만 수행한다. 별도 타이머, 신규 경제 규칙, 저장 구조 변경 없음. Canvas 없는 환경은 기존 SVG 표현으로 유지한다.
- 한칸역 한국어 2번 출구 / 일본어 동쪽 출구 불일치를 일본어 2번 출구로 맞췄다.

## 검증

- 기존 `npm test` 23묶음 통과: 저장/회계/운영/사건/시간/안정적인 버튼 회귀.
- `npm run test:browser` 10묶음 통과. 새 아트 검사 후 배송 경로 표시·겨울 야간 표현·회수 직원 구별을 보완하고 해당 도시 검사를 다시 통과했다.
- 도시 검사: 5상권, KO/JA, 4계절/날씨, 움직임 끔, 4화면 크기/업무창 열림·닫힘, 1/2/3배에서 6입지 실제 클릭, 실제 구매 기록 표시, 작업/배송 경로 표시, 60회 그리기 전후 전체 게임 상태 일치, 깊이 정렬, 공통 팔레트, 원래 버튼/캔버스 유지.
- 실제 브라우저 캡처로 상권별 구도 및 계절 화면 확인. 이전에 승인된 작은 아트 시험판은 계속 별도 주소에 보존한다.

## 남은 범위

입지별 세부 소품 후보를 모두 만든 것은 아니다. 공원의 놀이기구, 전문 시설의 추가 간판/출입구, 행사 후원 장식, 다양한 보행 경로/차량 이동, 원작 수준의 도시 밀도는 추가 미술 작업이다. 이번 화면 교체를 이벤트 아트나 장시간 성능/인간 플레이 밸런스 평가 완료로 해석하지 않는다. 확대 스크롤은 지원하나 드래그 카메라/회전은 없다.
