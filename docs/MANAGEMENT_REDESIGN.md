## 이번 개편의 완료 범위

1. 실제 달력과 계절. 새 게임은 2000-01-01, 자유 경영 기본. 1배속 하루 3분을 유지하며 16/64/256배속도 하나의 시계로 처리한다. 결산 경계를 넘은 시간은 버리지 않는다. 메뉴·사건·일시정지에서 추가 처리를 멈춘다.
2. 첫 거점의 사장은 최대 2대 경로를 직접 운행한다. 확장 거점은 관리자가 필요하며 배송 직원·차량의 점유와 화물 재고는 실제 자원이다. 판매 SKU·판매 추이·기기/창고/배송 재고로 발주하며 예정 지급액과 현금 유보금을 보호한다.
3. 계속 생산은 공장별 상품·목표 재고·생산량으로 설정한다. 원재료 발주→배송→생산 직원/관리자→공정→완제품 재고를 반복한다. 생산 직원과 관리자는 겸직할 수 있으나 교육/퇴사/피로로 작업 능력이 줄어든다.
4. 차입은 단일 계약 장부. 신용·순자산·실제 영업 현금흐름으로 한도를 계산한다. 운전자금 3개월 일시상환, 설비 24개월/원금 3개월 거치, 회사채 36개월/6개월 흑자 요건. 이자는 일별 비용 발생, 현금은 월 지급. 상환은 원금과 비용을 구분한다. 기존 계약 금리와 만기를 유지한다.
5. 월 급여·월 세금·월 결산과 10년치 월 장부. 연구는 기술 단계당 기본 90일 작업량이며 협력사 인원/동시 프로젝트/사내 연구소에 따라 달라진다. 이미 투자한 예산 내 단계 승인은 자동화할 수 있고 추가 예산은 별도 결정한다.
6. 경쟁사도 같은 발주/물류/제조/고용/자금 제약을 사용한다. 공세와 투자는 월 실적에 따라 결정한다.

## 저장 경계

`reference.management.version=1`과 회사별 `management`를 추가한다. 기존 저장은 자동 전환하지 않는다. 전환 전 원본을 `hankan-tycoon-v1-backup-before-management`에 보존한다. 기존 연구/외상/임대/차입 계약의 서명된 조건을 재설정하지 않는다. 새 연구와 새 차입부터 새 조건을 사용한다. 자동 운영은 전환 저장에서는 기본 꺼짐이다.

## 현재 검증

- 기존 16묶음 + 신규 3묶음 회귀, 기존/신규 장기 검사, 브라우저 5묶음 통과.
- 새 게임 기본 자금·추가 구매/회수 클릭 없는 3난수 × 731일: 영업·배치 보존·저장 재개·24개월 장부 대조.
- 24개월 상환 전 기간의 현금/원금/이자 보존, 연체 회복, 기존 계약과 백업 보존.
- 플레이어/AI의 실제 원재료 조달과 계속 생산, 교육 중 작업 정지.
- KO/JA 장부와 실제 클릭, 4화면 크기, 정지/배속/차입금의 노드 유지와 이동 0.
- 상세 수치와 한계: [검증 기록](VALIDATION_10.0.0.md). 공개 반영 상태는 [개발 현황](../DEVELOPMENT.md).

## 별도 남기는 범위

이 개편의 자동 검증은 재미의 증거가 아니다. 인간 플레이, 여러 성장 전략의 우열, 투자 회수·임금·AI 공격성의 본격 수치 보정은 별도로 수행한다. 초기 실험에서 자동 영업으로 현금 축적이 빨라지는 것을 확인했으며 장기 투자 비용과의 대응을 검사해야 한다. 도시 생활·건물 내부 배치·산업 전체 복제는 이전 제외 범위를 유지한다.
